## Held from: How switches become a calculator (wait until binary counting clicks)
Here's the next part.

Think of a car with a push start button. It only starts if your foot is on the brake AND you press the button. One without the other does nothing. Compare that to a house with a front door and a back door that both ring the same doorbell. It rings if someone presses the front OR the back.

Inside a chip, the brake, the button, and the doorbell are all tiny switches. Some switches decide whether another switch turns on, following rules like "both" or "either one." That's called a logic gate, and it's how switches start making decisions.

## Held from: Binary counting (wait until the rollover idea clicks with the new timer example)
Note: this was written with the odometer example he didn't know. When giving it, keep it word for word but swap "wheel" for "spot" so it fits the timer example.

Here's the next part.

Binary works exactly the same way, except each wheel only has 0 and 1 on it. Start at 0 0. Add one and it reads 0 1. Add one more, and the right wheel has nothing after 1, so it flips back to 0 and nudges the left wheel to 1. Now it reads 1 0, and in binary that means two. Add one more and it reads 1 1, which means three.

So in binary, "1 0" isn't ten. It's two, written with only 0s and 1s.
